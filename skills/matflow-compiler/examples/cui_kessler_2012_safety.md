|------|------|

| 规则ID | SAFE-C-004 |
| 目标步骤 | S02 |

| 溶剂 | THF (闪点-14C, 沸点66C) |
| 状态 | **blocked** |
| 消息 | 步骤S02涉及THF(闪点-14C)回流加热。THF极度易燃，加热必须使用回流冷凝管和通风橱。同时使用金属钠(水敏试剂)，存在多重安全风险。 |

所有涉及水敏/氧敏试剂的步骤(S02, S03, S04, S05, S07)均未在原文中指定气氛。以下试剂需要惰性气氛保护：
