## 2. 氢气与 NaBH4 相关风险 [重点]

NaBH4 是本次协议的核心风险源。其遇水、遇酸均分解产生易燃 氢 气 (H2)，在密闭空间或通风不足时可构成燃烧/爆炸风险。

### 2.1 SAFE-G-01: NaBH4 加入/存储 (WB-02)

| 字段 | 内容 |
|------|------|
| 检查类型 | water_reactive_reagent |
| 规则ID | SAFE-C-001 |
| 目标步骤 | WB-02 |
| 风险 | 遇水/湿气 → 放氢 + 放热 |
| 状态 | warning |
| 证据 | NaBH4 用量 1.5 mmol（explicit）；危险性为化学常识 (inferred) |
| 建议措施 | 保持干燥密封；通风橱；避免明火/火星；少量分次加入 |

### 2.2 SAFE-G-02: 电解阶段产氢 (WB-06)

| 字段 | 内容 |
|------|------|
| 检查类型 | hydrogen_evolution_electrolysis |
| 规则ID | SAFE-E-001 |
| 目标步骤 | WB-06 |
| 风险 | NaBH4 缓慢水解 + 可能阴极析氢，105 min 内持续产生 H2 |
| 状态 | **warning** |
| 建议措施 | 通风橱排风开启；电解池敞口自由排气；无点火源；记录电流电压察觉异常 |

### 2.3 SAFE-G-03: 酸淬灭（CRITICAL）(WB-09)

| 字段 | 内容 |
|------|------|
| 检查类型 | corrosion + H2 evolution |
| 规则ID | SAFE-C-002 |
| 目标步骤 | WB-09 |
| 风险 | **残留 NaBH4 + 1 M HCl → 剧烈快速放氢、喷溅、可能起火** |
| 状态 | **warning（需优先处理）** |
| 建议措施 | 0C冰浴、搅拌下**极慢滴加** 1 M HCl；现加现搅；通风橱；避免过量积存 |

> **说明**：若将大量酸一次性倒入含 NaBH4 体系，可能因快速放氢导致喷溅和燃烧。本协议设置 0C + 缓慢添加即可有效控制。

### 溶剂兼容性注意

- 原文明确：AR级 NMP 与无水 NMP 效果相当，说明微量水不影响反应，操作不苛刻。
- **切勿以 THF 替代 NMP**：THF 闪点 -14C（燃爆风险高）、且 NaBH4 在 THF 中溶解度差（文献中 THF/乙腈/二氧六环仅痕量产物）。

> **结论**: 本协议 **无高温/高压/密闭加热** 风险，核心化学风险集中在 **NaBH4 放氢**（制备、电解、水解、酸淬灭）。其中 **WB-09 酸淬灭（1M HCl + 残留 NaBH4）为最高风险步骤，必须 0°C+极慢添加**。结合 0 个 High Risk 缺失参数，协议从 blocked 放宽为 **needs_review**，确认上述安全事项后可按 SOP 执行。
