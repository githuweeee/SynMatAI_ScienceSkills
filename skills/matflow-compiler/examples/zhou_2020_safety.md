## 3. 警告项详情

### 3.1 SAFE-001: 密闭加热 (S07)

- **检查类型**: 密闭加热
- **规则ID**: SAFE-P-001
- **目标步骤**: S07（水热处理）
- **状态**: warning
- **描述**: 步骤S07涉及密闭水热釜在200C下加热。水在200C的饱和蒸汽压约1.6 MPa。
- **详情**:
  - 温度: 200 C
  - 是否密闭: 是
  - 估算压力: 1.6 MPa
  - 溶剂: 水
  - 溶剂沸点: 100 C
- **风险评估**: Teflon内衬水热釜是水热合成的标准设备，设计耐压通常>=2 MPa。但原文未给出水热釜的具体规格和耐压等级。
- **建议**:
  1. 确认水热釜耐压等级>=2 MPa
  2. 确认Teflon内衬完好无损
  3. 确认不锈钢外套无变形或腐蚀
  4. 严禁超量装液（装液量不超过釜体积的60%，即30 mL/50 mL = 60%，符合安全要求）
  5. 确保完全冷却至室温后再开釜
- **是否阻止执行**: 否（需确认设备规格）

### 3.3 SAFE-003: 易燃溶剂加热 (S14)

- **检查类型**: 易燃溶剂加热
- **规则ID**: SAFE-C-004
- **目标步骤**: S14（甲基化改性）
- **状态**: warning
- **描述**: 步骤S14涉及乙醇回流，推断温度约78C。乙醇闪点为13C。
- **详情**:
  - 溶剂: 乙醇
  - 闪点: 13 C
  - 沸点: 78 C
  - 操作温度: 78 C（推断）
- **风险评估**: 回流温度远超闪点，但回流操作使用冷凝管是标准安全做法。需确保冷凝管有效工作。
- **建议**:
  1. 使用回流冷凝管
  2. 确保冷却水持续供应
  3. 远离火源和热源
  4. 在通风橱内操作
  5. 准备灭火器
- **是否阻止执行**: 否

- **建议**:

### 3.5 SAFE-005: 有毒试剂操作 (S14)

- **检查类型**: 有毒试剂操作
- **规则ID**: SAFE-H-003
- **目标步骤**: S14（甲基化改性）
- **状态**: warning
- **描述**: 步骤S14在回流温度（78C）下使用氨水（1 mL，25 wt%）。氨水在高温下会加速挥发。
- **详情**:
  - 试剂: 氨水（25 wt%）
  - 危害: 呼吸道刺激、腐蚀性
  - 用量: 1 mL
  - 操作温度: 78 C
- **风险评估**: 氨水在回流温度下会释放大量氨气，风险较高。但使用回流冷凝管可减少挥发。
- **建议**:
  1. 必须在通风橱内操作
  2. 确保冷凝管有效冷凝
  3. 佩戴丁腈手套和护目镜
  4. 准备酸性中和液备用
  5. 注意氨气泄漏
- **是否阻止执行**: 否

## 8. 应急措施

### 8.1 氨气泄漏 (S09, S14)

1. 立即停止操作，关闭热源
2. 开启通风橱最大风量
3. 人员撤离至通风良好处
4. 用稀酸（如稀盐酸）中和溢出的氨水
5. 如吸入氨气，移至空气新鲜处，必要时就医

### 8.2 水热釜异常 (S07)

1. 如发现水热釜泄漏或变形，立即切断加热电源
2. 人员撤离至安全距离
3. 等待完全冷却至室温后再处理
4. 检查水热釜是否损坏，必要时更换
5. 严禁在高温状态下强行开釜

### 8.3 乙醇起火 (S01, S14)

1. 立即关闭热源
2. 使用二氧化碳或干粉灭火器灭火
3. 严禁用水扑救
4. 人员撤离并报警

### 8.4 断电恢复

1. 检查所有设备状态
2. 确认温度是否在安全范围内
3. 参考恢复方案（zhou_2020_recovery.yaml）执行
4. 记录断电时间和恢复时间

## 10. 结论
